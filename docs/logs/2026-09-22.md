  - **C4 (perf):** added in-flight GET de-dup to the shared web API client (`shared/api/client.ts`), keyed by path and self-cleaning once the request resolves, so two components mounting the same hook on one page share one round trip instead of doubling it. Scoped this narrower than the finding's full suggestion (a response cache + abort-on-unmount) - the de-dup alone fixes the concrete risk named (duplicate GETs from a double-mounted hook) without needing to thread an `AbortSignal` through every `api.*` call site in the app for a currently-hypothetical benefit.
