# Daily logs

One file per working day, named `YYYY-MM-DD.md`, capturing what was actually done that day (not the plan — the plan lives in the SRS/architecture docs). Keep entries short and factual.

## Template

```markdown
# YYYY-MM-DD

## Done
-

## Decisions
-

## Blockers / open questions
-

## Next
-
```

## Convention

- Create today's file before you start wrapping up for the day, not at the start (so it reflects what actually happened).
- Log decisions here even if they're small — the "why" often isn't visible in a diff or commit message.
- Link to relevant commits, PRs, or docs (e.g. `[ADR-0001](../adr/0001-....md)`) rather than repeating their content.
